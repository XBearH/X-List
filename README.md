# X-TodoList

基于 Vue3 + TypeScript + Vite 的角色化任务管理系统，支持学生/社畜双模式，集成周总结数据可视化与历史记录回溯。

## 技术栈
- Vue 3 (Composition API)
- TypeScript
- Vite
- Pinia
- Vue Router 4
- Element Plus / Dayjs / ECharts

## 功能模块

- [x] 项目脚手架与工程化配置（Vite + TS）
- [x] 基础路由与导航布局（4 页面结构）
